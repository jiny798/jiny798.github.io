## 글 작성 규칙

글은 `_posts` 폴더에 `YYYY-MM-DD-제목.md` 형식으로 추가합니다.

```markdown
---
title: 글 제목
date: 2026-11-09 22:30:00 +0900
categories: [대분류, 소분류]
tags: [태그1, 태그2]
---

본문 내용
```

코드 블록도 문법 강조와 함께 표시됩니다.

```sql
SELECT employee_id, name
  FROM employees
 WHERE department_id = 10;
```
